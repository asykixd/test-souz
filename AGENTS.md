# Product Card Assistant

The CLI is in `src/product_card/cli.py`, API and prompt in `openai.py`,
and input validation and rendering in `product.py` and `card.py`.
Keep implementation and repository documentation in English. Russian catalog
copy and source fixtures are product data.

Run `ruff format --check`, `ruff check` and `pytest` before committing.
Tests must run without an API key or network access.
